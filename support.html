Let’s get your shelf back in order.

Share what you’re seeing and where it happens. Choose the channel that works best for you.

↗PUBLIC CHANNEL

Open a GitHub issue

For users with GitHub, open a ticket in the Shelf support repository. A clear title and a short list of steps make the issue easier to understand.

Go to support issues ↗

Important: GitHub issues are public. Do not include passwords, access tokens, order details, payment data, private customer information, or other sensitive data.

@PRIVATE ALTERNATIVE

Email support

If you do not use GitHub—or your question includes information that should not be public—email the support team instead.

sheft.support@gmail.com

Please do not send passwords or payment information by email. The correct address is sheft.support@gmail.com.

MAKE IT EASY TO HELP

Include the useful context.

Tell us what you expected, what happened, and the steps that led there. Screenshots can help when they contain no private or sensitive information.

01

Installed Shelf version or the theme version shown in Shopify

02

Shopify admin area, page, template, or section involved

03

Browser and device, plus a concise reproduction path

04

Exact error text, with store-specific or personal details removed

SAFETY FIRST

Keep private details private.

Support requests should never require your Shopify password, verification codes, API keys, payment card numbers, or customer personal data. Redact those details from screenshots and copy. If a GitHub issue accidentally contains sensitive information, remove it promptly and use email for the private follow-up.
